# College-CRM - Java Swing Project
By Manglesh Tiwari

A complete College CRM System made in Java Swing + MySQL.

Features:
- Student Management
- Faculty Management
- Fees & Attendance
- Course Management

How to Run:
1. Import college_crm.sql.sql in MySQL Workbench
2. Open CollegeCRM folder in NetBeans / IntelliJ
3. Update DB username/password in code if needed
4. Run the project
